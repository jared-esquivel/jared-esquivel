# Install this GitHub profile

1. Open your GitHub profile repository: `https://github.com/jared-esquivel/jared-esquivel`.
2. Upload `README.md` to the repository root and upload the entire `assets/` folder, preserving the filenames.
3. Commit the changes and open `https://github.com/jared-esquivel` to view your profile.
4. Wait a few moments for third-party graphs to load. If a graph is unavailable, the README and animated SVGs still work.

## Files

- `README.md`: complete GitHub profile.
- `assets/hero.svg`: self-contained animated hero, based on the dark atmospheric reference video.
- `assets/stack.svg`: clean, self-contained tech-stack illustration with a gentle moving accent.

## Notes

- The animated title rotates between three roles. The first title is visible without animation. GitHub serves SVGs as images; no JavaScript or external CSS is required.
- SVGs include a legible static first frame. They may appear static when a browser or accessibility setting suppresses animation.
- GitHub's native contribution calendar already appears below the profile README. The optional third-party graphs are live images and cannot be guaranteed online.
- HackWatsonville is linked to the GitHub repositories listing and portfolio rather than to an unverified project repository. Replace this with a direct project URL when one is public.
- Do not add private Digital NEST projects as public repository links.
