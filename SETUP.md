# Pixel Coast v2 — installation

1. Download the ZIP and extract it. Preview `assets/sunset-hero.png` first: this is the full-size sunset artwork.
2. Open https://github.com/jared-esquivel/jared-esquivel and ensure you are on `main`.
3. Back up the existing README before replacing it.
4. Upload `README.md` and the entire `assets/` folder to the repository root, preserving the `assets/...` paths. Commit.
5. If not already installed, upload `.github/workflows/skyline.yml` to that exact path. Do not delete your existing snake workflow.
6. Go to Actions → Generate 3D Contributions → Run workflow. This requires Actions to be enabled and permission to write to the `output` branch.
7. Reload https://github.com/jared-esquivel. The hero should be a detailed sunset illustration, not a blank heading. If it is missing, verify `assets/sunset-hero.png` is on the `main` branch.
8. Verify external stats widgets individually. Third-party endpoints may be temporarily unavailable; the 3D chart appears only after its workflow succeeds. The snake path depends on your existing workflow output.

## Notes
- This version uses the original detailed sunset artwork, not the tiny placeholder animation from the previous package.
- The hero and footer are static pixel art. Do not describe them as animated. Stats update through external providers; 3D is generated by GitHub Actions.
- GitHub README pages do not support arbitrary CSS or JS; artwork and layout are implemented with GitHub-compatible images and Markdown.
- Project descriptions are deliberately conservative; check project details before claiming specific architecture or metrics.
